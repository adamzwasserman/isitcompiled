The program

One small program: build an order, add three items, apply a coupon, then compute the total, the discount, the tax and the grand total. We wrote it in 11 languages, as an average programmer would, with a class and separate method calls. We also wrote a version made of plain functions. Neither version is tuned for performance. The class timings leave out timestamp writes.

Everything ran in an Ubuntu 26.04 container on a rented eight-core virtual machine.

Where the data lives

The optimizer settings are in measured/optimizer-dial, and the memory layout runs are in measured/layout, measured/layout-others and measured/layout-raw. The scripts are in harness/dial, harness/layout and harness/checks. HotSpot's own log of what it inlined is in measured/optimizer-dial/inlining.

Limits

  • The server is a virtual machine and hides its real cache layout.
  • We ran each V8 setting in one process, so those rows have no spread figure.
  • PyPy implements Python 3.11, not 3.14.
  • Ruby has no JIT row, because our Ruby build lacks YJIT.
  • The program is small and every figure covers one scenario.
  • The memory layout pages demonstrate a textbook effect. They are not a study.
