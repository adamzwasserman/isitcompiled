Is Kotlin compiled or interpreted?

Kotlin is compiled. On the JVM, its compiler produces bytecode, and HotSpot's JIT compiles hot bytecode to machine code exactly as it does for Java. Kotlin/Native compiles to machine code ahead of time.

How it runs your code

The Kotlin compiler, kotlinc, targets several platforms. For the JVM it emits bytecode that the JVM runs and the JIT optimizes. Kotlin/Native produces native executables. Kotlin/JS emits JavaScript.

Does that make Kotlin slow?

On the JVM, Kotlin's speed is Java's speed, because the JVM's JIT compiles the bytecode. Turn the JIT off and it slows down by the amounts shown on the Java page.

Questions

Is Kotlin compiled to Java bytecode?

On the JVM, yes. Kotlin can also compile to native code with Kotlin/Native and to JavaScript with Kotlin/JS.

Is Kotlin slower than Java?

Kotlin on the JVM runs through Java's JIT, so equivalent code usually runs at a similar speed.

Does Kotlin need a JVM?

Only for the JVM target. Kotlin/Native produces executables without one.
